# CHAT LOCAL COM FILTRO DE MENSAGENS PROIBIDAS


Este projeto é um sistema de chat simples que permite a troca de mensagens em uma rede local (LAN). O objetivo principal é fornecer uma solução de comunicação em tempo real dentro de uma rede privada, com a adição de um sistema de bloqueio para impedir o envio de mensagens contendo palavras ou frases proibidas.

Funcionalidades
Chat em Rede Local: Permite a comunicação entre dispositivos conectados na mesma rede local.
Filtro de Mensagens Proibidas: Sistema de bloqueio que identifica e impede o envio de mensagens contendo palavras ou frases previamente definidas como inapropriadas, essas palavras ficam armazenadas em um banco de dados.

Interface Simples e Intuitiva: Interface de usuário amigável para facilitar a troca de mensagens.

Tecnologias Utilizadas
Linguagem de Programação: [Java]
Protocolos de Rede: [TCP/IP] para comunicação entre os dispositivos.
